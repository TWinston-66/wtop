# wtop

Minimal TUI Linux resource monitor in C++.

![screenshot](docs/screenshot.png)

## Requirements

- CMake 3.25 or newer
- C++26 (tested with GCC 15.3)

## Build

```sh
cmake -S . -B build
cmake --build build
```

## Usage

```sh
./build/wtop
```
